## איך מפעילים את המערכת במחשב

### פעם ראשונה בלבד
1. מתקינים את **Node.js** (גרסה 20 ומעלה) מהאתר https://nodejs.org (בוחרים בגרסה המסומנת **LTS**).
2. מורידים את הקוד: ב-GitHub לוחצים על הכפתור הירוק **Code** ואז **Download ZIP**, ופותחים את הקובץ בתיקייה כלשהי.
   (מי שמכיר Git יכול גם: `git clone -b claude/spec https://github.com/ShifiMarkus/Office-Secretary.git`)
3. פותחים חלון פקודות (ב-Windows: לוחצים על התיקייה עם מקש ימני ובוחרים **Open in Terminal**) ומקלידים:
   ```bash
   npm install
   ```
4. יוצרים את קובץ ההגדרות: מעתיקים את הקובץ `.env.example` לקובץ חדש בשם `.env` (באותה תיקייה). כרגע לא צריך לשנות בו כלום.

### בכל פעם שרוצים להפעיל
```bash
npm run dev
```
ואז פותחים בדפדפן את הכתובת: **http://localhost:3000**

במסך הכניסה בוחרים משתמש לדוגמה, מנהל/ת או עובד/ת, כדי לראות את המערכת מנקודת המבט של כל אחד.

> 💡 **טיפ:** כדי לראות שוב את הבלונים והזיקוקים של יום ההולדת, צריך להיכנס מחלון גלישה בסתר או להתחבר כמשתמש אחר. ההנפשה מוצגת פעם אחת ביום לכל משתמש.

### לאפס את נתוני ההדגמה
```bash
npm run seed -- --force
```

## הגדרת החיבורים (בסוף הפיתוח)
כל החיבורים מוגדרים **במקום אחד**: הקובץ `.env`. ליד כל שדה בקובץ יש הסבר בעברית:
- **Microsoft 365**: מזהה הארגון, מזהה האפליקציה והסוד. אחרי שממלאים אותם, מצב ההדגמה נכבה והכניסה נעשית עם החשבון הארגוני.
- **כתובת מייל** לשליחת הודעות מהמערכת.
- **בסיס נתונים** לשימוש אמיתי (PostgreSQL).
- **פרטי רכז/ת הנגישות** להצהרת הנגישות.
